# CI Actions

This repository contains a simple web project demonstrating the use of GitHub Actions for Continuous Integration (CI).

## Project Files

- `home.html` – Main HTML page of the project.
- `.github/workflows/` – Contains GitHub Actions workflow files.

## Features

- Basic HTML web page
- GitHub repository management
- Continuous Integration using GitHub Actions
- Automated workflow execution

## Technologies Used

- HTML5
- GitHub
- GitHub Actions
